# kakitome プライバシーポリシー

最終更新日: 2026年10月3日

kakitome（以下「本アプリ」）は、メモやチェックリストを端末内に保存する、サーバーを持たないアプリです。このページでは、本アプリがどのような情報を扱い、どこへ送るかを説明します。

## 要点

- **開発者のサーバーはありません。** メモなどの内容が、開発者や第三者のサーバーへ送られることはありません。
- 広告、アクセス解析、利用状況の追跡は行いません。
- Google ドライブとの同期は、**ご自身で有効にしたときだけ**行われ、データはご自身の Google アカウントの中にだけ保存されます。

## 本アプリが扱う情報

### 端末内に保存する情報

あなたが作成したメモ（タイトル・本文）、チェックリスト、リマインド、添付した画像は、端末内のデータベースとファイルに保存されます。本アプリの外へ出ることはありません（下記の同期を有効にした場合を除く）。

添付した画像からは、撮影位置などの付加情報（EXIF）を取り除いてから保存します。

### Google ドライブとの同期（任意）

設定画面から「Google アカウントで同期を始める」を選ぶと、Google のサインインを経て、ご自身の Google ドライブにある**本アプリ専用の領域**（appDataFolder）に、メモなどのデータを保存します。

- 要求する権限は、この専用領域へのアクセス（`drive.appdata`）と、サインインに必要な基本情報（名前・メールアドレス）だけです。ドライブ内のほかのファイルには、アクセスできません。
- この専用領域は、あなたの Google ドライブの画面からは見えず、本アプリ以外は読み書きできません。
- サインインしたアカウントのメールアドレスは、設定画面に表示するためだけに使います。本アプリは、これを保存したり、送信したりしません。
- 同期したデータの保存先は Google です。Google による取り扱いは、[Google のプライバシーポリシー](https://policies.google.com/privacy)に従います。

本アプリによる Google API から取得した情報の使用と転送は、制限付き使用の要件を含む [Google API サービスのユーザーデータに関するポリシー](https://developers.google.com/terms/api-services-user-data-policy)に準拠します。
(The use and transfer of information received from Google APIs to any other app by kakitome will adhere to the Google API Services User Data Policy, including the Limited Use requirements.)

## 本アプリが使う権限

| 権限 | 使う目的 |
| --- | --- |
| 通知 | リマインドの時刻に通知を表示するため |
| アラームとリマインダー（正確なアラーム） | リマインドを指定した時刻ちょうどに鳴らすため（許可は任意。許可しなくても、数十秒から1分ほど遅れて鳴ります） |
| インターネット・ネットワークの状態 | Google ドライブとの同期と、Wi-Fi 接続時のみ画像を送受信する設定のため |
| 起動時の処理（再起動後の再予約） | 端末の再起動後に、リマインドを予約し直すため |
| 振動 | 通知の振動のため |

画像の選択には、システムのフォトピッカーを使います。本アプリが写真ライブラリ全体を読み取ることはありません。

## 情報の削除

- **端末内のデータ**: 本アプリをアンインストールすると、端末内のデータはすべて削除されます。メモ単位の削除は、アプリ内で行えます。
- **Google ドライブ上のデータ**: 設定画面の「サインアウト」で同期を止められます（サインアウトしても、ドライブ上のデータは残ります）。ドライブ上のデータを消すには、Google ドライブの設定の「アプリの管理」から kakitome を選び、「非表示のアプリデータを削除」を実行してください。Google アカウントの「サードパーティによるアクセス」から、本アプリの権限を取り消すこともできます。

## 子どものプライバシー

本アプリは、13歳未満の子どもを対象としておらず、子どもの個人情報を意図して収集することはありません。

## 変更について

このポリシーを変更するときは、このページを更新し、最終更新日を改めます。
