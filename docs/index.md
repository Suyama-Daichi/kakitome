# kakitome（書き留め）

チェックリスト・リマインド・Android ウィジェットに対応した、サーバーを持たないローカルファーストのメモアプリです。

- メモ・チェックリスト・画像・リマインドは、まず端末の中に保存されます
- 複数の端末で使いたいときだけ、ご自身の Google ドライブの専用領域に同期できます（任意）
- 開発者のサーバーはなく、開発者があなたのデータを受け取ることはありません

- [プライバシーポリシー](privacy)
- ソースコード: [github.com/Suyama-Daichi/kakitome](https://github.com/Suyama-Daichi/kakitome)
